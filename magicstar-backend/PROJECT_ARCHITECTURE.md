# 魔法星球 - 项目架构文档

## 项目概述

魔法星球是一个基于微信小程序的占卜平台，提供塔罗牌占卜、星座运势、AI智能解读等服务。

## 技术架构

### 后端技术栈
- **框架**: Node.js + NestJS
- **数据库**: MySQL (主) + Redis (缓存)
- **ORM**: TypeORM
- **API文档**: Swagger
- **测试**: Jest
- **代码规范**: ESLint + Prettier

### API接口

#### 已实现的API端点
- `/auth/*` - 用户认证相关 (登录、注册、密码重置)
- `/users/*` - 用户管理 (个人信息、安全设置)
- `/divination/*` - 占卜服务 (塔罗牌占卜、历史记录)
- `/fortune/*` - 运势服务 (每日运势、运势历史)
- `/ai/*` - AI服务 (智能解读、AI管理)
- `/mall/*` - 商城功能 (商品管理、购物车、订单)
- `/payment/*` - 支付处理 (微信支付、支付宝支付)
- `/finance/*` - 财务管理 (财务统计、报表、对账)
- `/content/*` - 内容管理 (文章发布、内容分类)
- `/notifications/*` - 通知服务 (消息推送、邮件通知)
- `/health` - 健康检查端点
- `/metrics` - Prometheus监控指标
